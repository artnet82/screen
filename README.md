# screen
📖 Око — запись экрана. Краткая инструкция

🚀 Запуск

Запустите ScreenRecorder.exe. Откроется окно с настройками записи.

📝 Запись

1. (Необязательно) Введите название файла в поле «Название». Если оставить пустым — файл получит имя recording_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.mp4.
2. Выберите область:
   · «Выбрать область» — экран потемнеет. Зажмите левую кнопку мыши и растяните рамку вокруг нужного участка. Отпустите — координаты сохранятся.
   · Esc — отменить выбор.
   · «Сбросить» — вернуться к записи всего экрана.
3. FPS — плавность видео. 20 — оптимально. 15 — для слабых ПК, 30 — для динамичных сцен (файл будет больше).
4. Системный звук — поставьте галочку, если нужно записывать звуки из колонок/наушников (музыка, видео, игра). Если галочку снять — запишется только видео без звука.
5. Нажмите «Начать запись».

⏸️ Управление во время записи

Кнопка Действие
Пауза / Продолжить Приостановить и возобновить запись
Стоп Остановить и сохранить файл

На время паузы и видео, и звук не записываются. После возобновления синхрон восстанавливается автоматически.

💾 Куда сохраняется

Файлы попадают в папку Видео вашего профиля Windows:

```
C:\Users\<Ваше_имя>\Videos\
```

Когда нажмёте Стоп, в статусе появится «Сохранение (кодирование)...» — идёт сжатие видео через ffmpeg. Это может занять от нескольких секунд до минуты (зависит от длины записи). Не закрывайте окно, пока статус не сменится на зелёный.

⚙️ Формат и размер

· Формат: MP4 (H.264 + AAC) — открывается любым плеером, легко загружается на YouTube и в мессенджеры.
· Файлы сжимаются автоматически, поэтому итог обычно в 3–5 раз меньше, чем при «сырой» записи.

❗ Если что-то не так

· Видео без звука — проверьте, включены ли колонки/наушники (loopback работает только при активном устройстве воспроизведения).
· Чёрный экран при записи игры — некоторые игры с защитой вывода не записываются. Отключите в игре режим «Fullscreen Exclusive», поставьте «Borderless Window».
· Предупреждение «ffmpeg не найден» — приложение сохранит видео без звука и отдельный WAV-файл. Сообщите разработчику.
· Запись обрезается в узкой области — минимальный размер области: 40×40 пикселей.

🛑 Закрытие

Просто закройте окно. Если запись ещё идёт, программа спросит, остановить её или нет.
